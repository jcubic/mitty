## Installation

```bash
npm install @jcubic/mitty
```

## Usage

### ESM / TypeScript

```typescript
import * as mitty from '@jcubic/mitty';
```

### Browser (`<script>` tag)

```html
<script src="https://unpkg.com/@jcubic/mitty/dist/index.global.js"></script>
<script>
  // available as the `Mitty` global
</script>
```
